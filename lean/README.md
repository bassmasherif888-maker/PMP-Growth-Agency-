# PMP: revised lean edition

The current delivery replaces the long bilingual pack with one five-page operating guide and one ten-slide deck in each language. Arabic is written in professional Egyptian Arabic, independently of the English wording. Prior long documents remain reference archives.

[View and download both editions](index.html).

- Word and PowerPoint text remains editable.
- PDFs are reading copies of those same Office files.
- Burgundy/yellow palette follows Direction 01. Arabic uses IBM Plex Sans Arabic with explicit regular/bold weights, RTL paragraphs and right-first slide reading order; English uses Montserrat.
- Confirmed operating rules are retained. Proposed routines and unresolved authority, financial, access and storage decisions are labelled.
- Monthly appraisal method is summarized; no actual staff records are included.

Rebuild with `python lean/build.py` and `python lean/build_page.py`; render PDFs with LibreOffice. Install the fonts before editing Office files for consistent appearance.
