# English and Arabic final delivery

Open [the bilingual download page](index.html) for all five deliverables in each language. Both editions include monthly performance appraisals. Word and PowerPoint remain editable; PDFs are reading copies.

Arabic uses IBM Plex Sans Arabic, RTL paragraphs and mirrored slide layouts. Install the font to preserve appearance when editing. Original appraisal archives and completed employee records are private and are not included.

Rebuild: run the English generators, resolve the translation dictionary, then run `python arabic/build_arabic.py`. Re-render PDFs with LibreOffice after changing Office files.
